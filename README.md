# Restaurant Control

Restaurant management system for Ethiopian restaurants and cafes: menu, orders, tables, kitchen, billing and inventory.

## Stack
Next.js, TypeScript, Tailwind, Supabase.

## Run locally
1. `npm install`
2. Create `.env.local` with `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` and `SUPABASE_SERVICE_ROLE_KEY`
3. Run `supabase/schema.sql` in the Supabase SQL Editor
4. `npm run dev`
